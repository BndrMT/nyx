_الخصوصية جوهر Nyx — نجعلها أكثر متانة._

### 2.1 — إضافة CSP في `index.html`
```html
<meta http-equiv="Content-Security-Policy"
  content="default-src 'self';
    font-src 'self' https://fonts.gstatic.com;
    style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
    img-src 'self' data: blob:;
    script-src 'self';
    connect-src 'self'">
```

## المرحلة 4️⃣ — ترقية الصوت البريميوم (Audio Premium)
_تحويل تجربة التنفس من جيدة إلى سينمائية._

### 4.1 — فصل مصدري صوت مستقلين
- **قناة Noise1** → صوت الرياح (Lowpass مع LFO سريع)
- **قناة Noise2** → صوت المطر/الخرير (Bandpass مع عزل ترددي مختلف)

### 4.2 — إضافة طبقة Oscillator
- Oscillator عند 60-80Hz (نبض هادئ/طبلة قلب)
- اختلاط منخفض جداً (gain 0.02) يعطي إحساساً تحت الشعور

### 4.3 — إضافة Convolver Reverb
- توليد Impulse Response بسيط (صدى غرفة صغيرة 0.3s)
- يعطي عمقاً مكانياً للصوت

### 4.4 — تحسين انتقالات Morph
- استخدام S-curve بدلاً من exponential ramp
- تدرج 3-5 ثوانٍ بين المراحل (شهيق → احتجاز → زفير)

### 4.5 — إضافة مرحلة "احتجاز" مميزة صوتياً
- صوت مختلف عن الشهيق والزفير (تردد ثابت منخفض)
- يوحي بالسكون والطمأنينة

### 4.6 — تحكم يدوي في الصوت
- زر كتم/تشغيل (موجود)
- إضافة تحكم في مستوى الصوت (Slider)
- إضافة مؤقت الجلسة (1-5-10 دقائق)

### 8.1 — إنشاء ملف `vercel.json`
```json
{
  "version": 2,
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "framework": "vite",
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
```

### 8.2 — الدفع إلى GitHub
```bash
git remote add origin https://github.com/BndrMT/nyx.git
git push -u origin master
```

### 8.3 — الربط مع Vercel
- خيار 1: `npx vercel` من الجهاز
